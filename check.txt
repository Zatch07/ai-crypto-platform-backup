MONITORING PORTS & COMMANDS:
- Web Application: http://localhost:3000 (Proxy -> Blue/Green)
- Jenkins CI/CD: http://localhost:8080
- Prometheus Engine: http://localhost:9090
- Grafana Telemetry: http://localhost:3001 (Auto-loaded dashboard: "Crypto Platform - Production Telemetry")
- Start Monitoring: docker compose -f docker-compose.monitoring.yml up -d
- Stop Monitoring: docker compose -f docker-compose.monitoring.yml down
